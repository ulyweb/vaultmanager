01 · Profiles

One profile per person.

Each profile is its own vault with its own master password. Nothing is shared between them.

  • Create Pick a name, a picture and Auto, Dark or Light. Ask for a passphrase and you get ten random words, about 103 bits.
  • Import Bring a whole profile back from an encrypted backup, with a new master password or the backup's own.
  • Delete Removing a profile wipes that vault from this device, and only after you confirm.

    Can you trust it? The honest answer.

    • Standard encryption. AES-256-GCM, done by your browser’s own crypto engine, with your master password slowed down by 600,000 rounds. Nothing is home-made.
    • Nothing to hack on our side. No server, no account, no tracking. Watch the Network tab in your browser: nothing is sent while you use it.
    • Readable and tested. The source code is public, and automated tests in Chrome, Firefox and Safari engines run on every change.
    • A browser app, a serious one. The encryption itself runs as native code inside the browser, the same kind of well-tested crypto library a Rust app would use. Native apps still win on wiping memory, and a hosted web app gets its updates from its host, so the single offline file with a checksum is there if you want it frozen.
    • What nobody can promise. No software is “guaranteed” secure, and this one has not had an independent audit. It cannot protect you from malware on your device, a weak master password, or a forgotten password with no recovery key. Keep a backup.
